5. Data Architecture

MongoDB Schema & Snapshot Pattern

How documents are structured and how historical financial integrity is maintained.

Core Collections

📁 users: id, name, email (unique), passwordHash, phone, address, role
📁 categories: id, name, description, imageUrl, active
📁 food_items: id, name, categoryId, price, available, imageUrl
📁 carts: id, customerId, items: [{foodItemId, quantity}]
📁 orders: id, customerId, customerName, totalAmount, orderStatus, items: [...]

The Snapshot Pricing Pattern

If food items simply referenced foodItemId, changing a dish price tomorrow would retrospectively corrupt yesterday's customer receipts.

OrderItem {
  foodItemId, foodName, unitPrice, quantity, lineTotal
}

Snapshots freeze exact prices at checkout for audit and accounting consistency.

6. Application Security

Stateless Authentication & Authorization

Zero server-side sessions, encrypted passwords, and multi-tenant isolation.

1. Password Hashing

BCrypt encryption with cryptographically random salting. Passwords and hashes are never exposed in DTO responses or client storage.

2. Stateless JWT

Tokens signed with HS256 containing user ID and Role. Injected into every authorized request via Authorization: Bearer <token>.

3. Authorization Matrix

Strict role check: Public for browsing, CUSTOMER for cart/checkout, and ADMIN for menu/status management. Customers cannot access other users' orders.

7. Core Business Logic

Order Lifecycle State Machine (FSM)

Preventing illegal state transitions and ensuring order fulfillment integrity.

[1] PENDING ➔ [2] CONFIRMED ➔ [3] PREPARING ➔ [4] OUT_FOR_DELIVERY ➔ [5] DELIVERED

Allowed Transitions

  • PENDING can move to CONFIRMED or CANCELLED
  • PREPARING can move to OUT_FOR_DELIVERY or CANCELLED
  • OUT_FOR_DELIVERY can move to DELIVERED

Terminal State Enforcement

  • DELIVERED: Terminal state. Automatically sets payment status to PAID for COD.
  • CANCELLED: Terminal state. Cannot be reopened.
  • Illegal jumps (e.g. DELIVERED ➔ PENDING) throw InvalidStatusTransitionException (400).
